# Passkeys & WebAuthn

open-auth supports the WebAuthn standard, allowing users to sign in with biometric sensors (TouchID, FaceID) or hardware security keys (YubiKey).

## Key Concepts

- **Attestation**: The process of registering a new passkey.
- **Assertion**: The process of signing in with an existing passkey.
- **Challenge**: A random value generated by the server to prevent replay attacks.

## Registration

1. **Create Options**: Generate registration options for the client.
2. **Client Interaction**: Use `navigator.credentials.create()` on the browser.
3. **Verification**: Send the response back to the server for validation and storage.

```typescript
// Server: Generate options
const options = await auth.passkey.generateRegistrationOptions(user);

// Server: Verify response
const verification = await auth.passkey.verifyRegistrationResponse(credential);
```

## Authentication

Signing in is even simpler:

1. **Get Options**: Generate authentication options.
2. **Client Interaction**: Use `navigator.credentials.get()`.
3. **Verification**: Verify the signature on the server.

```typescript
const { sessionToken, user } = await auth.passkey.authenticate(credential);
```

> [!NOTE]
> Passkeys are highly recommended for their resistance to phishing and superior user experience.
