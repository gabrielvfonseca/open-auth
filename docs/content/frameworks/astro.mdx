# Astro Integration

This guide shows you how to integrate `open-auth` into an Astro project using middleware for session management.

## Installation

```bash
bun add open-auth
```

## Middleware Setup

In Astro, the best place to handle authentication is in the middleware.

```typescript
// src/middleware.ts
import { defineMiddleware } from "astro/middleware";
import { auth } from "open-auth";

export const onRequest = defineMiddleware(async (context, next) => {
	const sessionId = context.cookies.get(auth.session.cookieName)?.value;
	if (!sessionId) {
		context.locals.user = null;
		context.locals.session = null;
		return next();
	}

	const { session, user } = await auth.validateSessionToken(sessionId);
	if (session) {
		context.cookies.set(auth.session.cookieName, session.id, {
			path: "/",
			httpOnly: true,
			sameSite: "lax",
			secure: import.meta.env.PROD,
			expires: session.expiresAt
		});
		context.locals.session = session;
		context.locals.user = user;
	} else {
		context.locals.session = null;
		context.locals.user = null;
	}
	return next();
});
```

## Accessing User Data

In your Astro components or pages:

```astro
---
const { user } = Astro.locals;
---

{user ? <p>Welcome, {user.username}</p> : <p>Please sign in</p>}
```
