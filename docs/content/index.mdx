# Introduction

open-auth is a high-level authentication service designed to facilitate advanced account management and verification workflows. It orchestrates complex flows involving multiple domain packages like email, database, and identity.

## Why open-auth?

- **Modular Architecture**: Built on top of specialized domain packages.
- **Developer First**: Clean, intuitive API that works across any framework.
- **Production Ready**: Built-in support for WebAuthn, MFA, and Security best practices.
- **Framework Agnostic**: First-class support for Next.js, Nuxt, Remix, Astro, Hono, Express, and Elysia.

## Core Features

- **Authentication**: Email/Password, Passkeys (WebAuthn), OAuth, SSO (SAML/OIDC).
- **Session Management**: Secure cookie handling, session invalidation, and device tracking.
- **MFA (Multi-Factor Authentication)**: TOTP support out of the box.
- **Identity Logic**: Account linking, username management, and email verification.
- **Enterprise Features**: Organization support, Audit logging, and SSO.
