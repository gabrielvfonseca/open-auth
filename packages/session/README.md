# @open-auth/session

The session management service for Open-Auth. It handles the lifecycle of user sessions across different devices and platforms.

## Installation

```bash
bun add @open-auth/session
```

## Features

- **Session Lifecycle**: Creation, validation, renewal, and revocation of sessions.
- **Device Management**: Tracking and managing devices associated with active sessions.
- **Cross-Platform Support**: Consistent session handling for web and mobile apps.
- **Security**: Robust protection against session hijacking and fixation.
