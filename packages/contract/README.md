# @open-auth/contract

The shared schema and type contract for the Open-Auth monorepo. It ensures type safety and data consistency between the frontend, backend, and various microservices.

## Installation

```bash
bun add @open-auth/contract
```

## Features

- **Standardized Schemas**: Zod-based schemas for all major entities.
- **Type Safety**: TypeScript interfaces automatically generated from schemas.
- **Microservice Sync**: Ensures all services speak the same data "language".
