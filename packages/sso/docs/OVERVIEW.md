# SSO Package Overview

The `@open-auth/sso` package allows organizations to manage their own users' access to the Open-Auth platform using existing enterprise identity providers.

## Key Modules

- **SAML Core**: Implementation of the SAML 2.0 protocol for authentication.
- **Request Store**: Internal management of SAML requests and relay states.
- **Identity Provider (IdP) Metadata**: Loading and parsing of XML metadata from providers like Okta.
