# @open-auth/core

The core library for the Open-Auth monorepo, providing essential utilities, error handling, logging, and validation logic used across all services.

## Installation

```bash
bun add @open-auth/core
```

## Features

- **Validation**: Strict schema validation using Zod.
- **Rate Limiting**: Redis-backed rate limiting for high-performance protection.
- **Logging**: Standardized logging interface.
- **Encryption**: Secure cryptographic primitives.
- **Error Handling**: Unified error classes for the entire platform.
