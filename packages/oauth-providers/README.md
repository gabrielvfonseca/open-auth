# @open-auth/oauth-providers

Configuration and client logic for specific OAuth providers (Google, GitHub, etc.) used by the Open-Auth platform.

## Installation

```bash
bun add @open-auth/oauth-providers
```

## Supported Providers

- **Google**
- **GitHub**
- **Discord**
- **Twitter/X**

## Features

- **Pre-configured Clients**: Ready-to-use configurations for popular IDPs.
- **Type-Safe Env**: Validation of credentials and redirect URIs.
- **Metadata Handling**: Simplified access to provider-specific user info.
