# open-auth

High-level authentication service for the Open-Auth platform. It provides sophisticated flows for account management, email verification, and username handling.

## Installation

```bash
bun add open-auth
```

## Features

- **Email Verification**: Fully integrated verification loop.
- **Account Deletion**: Secure account teardown processes.
- **Username Management**: Handling of unique user identifiers.
- **Action Wrappers**: Consistent patterns for wrapping auth-related actions.
