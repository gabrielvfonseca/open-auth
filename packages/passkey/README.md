# @open-auth/passkey

The WebAuthn and Passkey service for Open-Auth. It provides a secure, passwordless authentication method using biometric or hardware-based credentials.

## Installation

```bash
bun add @open-auth/passkey
```

## Features

- **WebAuthn Support**: Standard-compliant implementation for passkeys.
- **Registration Flow**: Logic for enrolling new hardware/biometric keys.
- **Authentication Flow**: Secure login using registered passkeys.
- **Credential Management**: Safe storage and retrieval of public key credentials.
