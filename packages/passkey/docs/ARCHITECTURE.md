# Passkey Architecture

The Passkey package implements the FIDO2/WebAuthn specification and integrates with the Identity and Database packages.

## Structure

```
src/
├── webauthn.ts             # Low-level crypto and spec logic
├── webauthn-verification.ts # Domain workflows
├── webauthn-config.ts       # RP metadata
└── actions.ts              # Client-facing actions
```

## Security Design

1. **Challenges**: Every operation is tied to a secure, random challenge to prevent replay attacks.
2. **Signature Verification**: Uses standard cryptographic libraries to verify signatures generated by the authenticator.
3. **RP Consistency**: Ensures that the Relying Party ID matches the origin to prevent domain-spoofing.
