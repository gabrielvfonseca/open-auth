# @open-auth/recovery

Account recovery service for Open-Auth. It provides mechanisms for users to regain access to their accounts when they have lost their primary authentication factors.

## Installation

```bash
bun add @open-auth/recovery
```

## Features

- **Master Recovery Codes**: Generation of high-entropy backup codes for account-wide recovery.
- **Recovery Workflows**: Secure processes for verifying recovery attempts.
- **Audit Integration**: Full logging of all recovery-related activities.
- **Security**: Measures to prevent brute-forcing and unauthorized recovery attempts.
