# @open-auth/guardian

The advanced security and threat protection service for Open-Auth. It acts as an intelligent shield, protecting the platform from automated attacks, malicious actors, and unauthorized access attempts.

## Installation

```bash
bun add @open-auth/guardian
```

## Features

- **Account Lockout**: Sophisticated logic to prevent brute-force attacks by temporarily locking suspicious accounts.
- **Risk Detection**: Real-time analysis of session and request metadata to identify high-risk activity.
- **Bot Protection**: Seamless integration with Cloudflare Turnstile.
- **Email Filtering**: Proactive blocking of disposable or untrusted email domains.
- **Session Intelligence**: Tracking and scoring of user session behavior.
