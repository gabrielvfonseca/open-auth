# Telemetry Package Overview

The `@open-auth/telemetry` package provides the visibility needed to operate the Open-Auth platform at scale. It utilizes OpenTelemetry standards to ensure interoperability with modern monitoring tools.

## Key Modules

- **Metrics**: Logic for recording business and technical metrics.
- **Tracing**: Instrumentation for capturing the lifecycle of a request.
- **Exporters**: Adapters for sending data to external monitoring platforms.
