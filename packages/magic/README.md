# @open-auth/magic

The magic link authentication service for Open-Auth. It provides a simple, email-based passwordless login flow using short-lived secure links.

## Installation

```bash
bun add @open-auth/magic
```

## Features

- **Link Generation**: Secure, cryptographically signed magic links.
- **Email Delivery**: Integrated with the Email package for reliable delivery.
- **Verification**: Smooth verification flow for one-time links.
- **Security**: Protection against link spoofing and replay attacks.
