# Magic Package Overview

The `@open-auth/magic` package implements the magic link authentication pattern. Users receive a link via email and are logged in upon clicking it, bypassing the need for passwords.

## Key Concepts

- **Magic Link**: A URL containing a secure, short-lived token.
- **Token Lifecycle**: Generation, delivery, and one-time consumption.
- **User UX**: Frictionless entry for users who have access to their email.
