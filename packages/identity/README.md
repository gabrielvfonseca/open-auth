# @open-auth/identity

The identity management package for Open-Auth. It handles the low-level logic for users and their associated authentication accounts.

## Installation

```bash
bun add @open-auth/identity
```

## Features

- **User Management**: Creating, retrieving, and updating user profiles.
- **Account Linking**: Managing multiple authentication methods (password, OAuth) linked to a single user.
- **Identity Abstraction**: A unified way to interact with different identity providers.
