# OAuth Package Overview

The `@open-auth/oauth` package manages external identity delegation and authorization. It allows users to log in using third-party services like Google or GitHub.

## Key Modules

- **OAuth Client**: Logic for initiating and completing the OAuth flow with external providers.
- **OAuth Server**: Implements the server side of the OAuth 2.0 specification.
- **Constants**: Shared identifiers and configuration keys for the OAuth system.
