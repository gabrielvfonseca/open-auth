# @open-auth/oauth

The central OAuth 2.0 service for Open-Auth. It handles the core OAuth/OpenID Connect logic, token exchange, and authorization server capabilities.

## Installation

```bash
bun add @open-auth/oauth
```

## Features

- **Standardized Flows**: Authorization Code, Refresh Token, and more.
- **Provider Abstraction**: Unified interface for interacting with various OAuth providers.
- **OAuth Server**: Capabilities to act as an authorization server for third-party integration.
- **Security**: Robust handling of PKCE, state tokens, and secure redirection.
