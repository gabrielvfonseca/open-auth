# Audit Package Overview

The `@open-auth/audit` package ensures that every critical action in the Open-Auth platform is recorded. It provides the "Who, What, Where, and When" for every security event.

## Key Concepts

- **Audit Event**: A single record of an action taken by a user or system process.
- **Actor**: The entity performing the action (User, API Key, System).
- **Target**: The resource being acted upon (Account, Session, Setting).
- **Outcome**: Whether the action succeeded, failed, or was blocked.
