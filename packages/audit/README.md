# @open-auth/audit

The auditing service for Open-Auth. It provides a structured, immutable trail of all security-relevant events across the entire platform, essential for compliance and forensic analysis.

## Installation

```bash
bun add @open-auth/audit
```

## Features

- **Structured Logging**: Standardized event format including actor, action, timestamp, and metadata.
- **Immutable Trail**: Designed for storage in secure, tamper-evident data stores.
- **Compliance Ready**: Helps meet requirements for SOC2, GDPR, and other regulatory frameworks.
- **Searchable Events**: Efficient indexing of audit logs for rapid retrieval and investigation.
