# @open-auth/email

The email delivery service for Open-Auth. It provides a unified interface for sending transactional emails, managing templates, and integrating with providers like AWS SES.

## Installation

```bash
bun add @open-auth/email
```

## Features

- **Template System**: Support for dynamic HTML and text email templates.
- **Provider Integration**: Pre-configured support for AWS SES.
- **Reliability**: Integrated retry logic and error handling for delivery failures.
- **Type-Safe Payloads**: Validated data structures for email components.
