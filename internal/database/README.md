# @open-auth/database

The data access layer for the Open-Auth platform, utilizing Prisma for type-safe database interactions and migration management.

## Installation

```bash
bun add @open-auth/database
```

## Features

- **Type-Safe Queries**: Automatically generated TypeScript client based on the Prisma schema.
- **Migrations**: Robust migration system for evolving the database schema.
- **Connection Pooling**: Pre-configured connection management for PostgreSQL.
- **Seeding**: Integrated data seeding for development and testing.
